# Marketplace listing notes

This repository is prepared for the GitHub Marketplace.

- Name: JEV Cloud Cost Guardian
- Short description (≤125 chars): Uses Jev to approve, warn, block, or review cloud cost changes against a budget.
- Primary category: Continuous integration
- Additional category: Deployment
- Icon: `dollar-sign`
- Color: green
- The listing must state that the action sends cost metadata to the configured Jev provider and does not change cloud infrastructure.
- GitHub has no API for Marketplace publication. After each release, open the release edit page, check **Publish this Action to the GitHub Marketplace**, confirm 2FA, and publish.
